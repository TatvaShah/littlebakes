# LittleBakes

Prospect demo for LittleBakes, custom and celebration cakes in Mississauga, Ontario. Built for ClaudAura IT Solutions.

Orders are placed by Instagram DM. The order note is copied to the clipboard, then the Instagram chat opens.

## Scripts

```
npm install
npm run dev
npm run build
```

No environment variables are required. On Vercel the site URL is read from the platform.
